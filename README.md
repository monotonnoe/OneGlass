# OneGlass

Модуль LSPosed, который переносит **Liquid Glass из iOS 27** на рабочий стол **One UI 8.5** (One UI Home, `com.sec.android.app.launcher`).

Что становится стеклянным:

| Элемент | Как сделано | Параметры из Figma |
|---|---|---|
| Док | стеклянная подложка вокруг `HotseatCellLayout` | 368×103 pt, радиус 38, сглаживание углов 0.6 |
| Индикатор страниц | стеклянная таблетка в стиле «Search» за точками | 77×30 pt, полностью скруглённая |
| Виджеты | стеклянный фон плюс обрезка по непрерывному скруглению | радиус 26 dp, настраивается |
| Папки | стеклянная иконка папки | радиус 22.37% стороны, как у иконок iOS |
| Иконки | световая кромка по контуру | — |

## Материал

Параметры сняты из файла Figma «100+ Apple iOS 27 Screens», фрейм `Home Screen - iPhone` → `Dock` / `Search Field` → `Materials`:

- `Fill + Shadow`: заливка `#999999`, непрозрачность 33%, режим наложения **Luminosity**; тень 2% по y = 8, r = 15; тёмная кромка 0.5 pt (`#CCCCCC`, Linear Burn).
- `Glass Effect`: эффект **GLASS** (преломление); внутренние блики **Linear Dodge** `#282828`: волоски 1.25 pt и мягкое свечение 10 pt сверху и снизу.

В модуле это один AGSL-шейдер (`glass/GlassShader.java`). Он делает:

1. непрерывно скруглённый прямоугольник через SDF;
2. **преломление** у края: обои подтягиваются наружу по нормали с круговым профилем линзы;
3. **дисперсию**: каналы R, G и B берутся с разным смещением;
4. яркость и насыщенность фона, затем слой яркости `#999999 @ 33%` из макета;
5. **блики**: волосок 1.25 dp и внутреннее свечение, сильнее там, где край обращён к свету;
6. тёмную кромку 0.5 dp снаружи.

## Откуда берётся фон под стеклом

Окно лаунчера прозрачное, а обои рисуются в отдельной поверхности под ним, так что прочитать их из view нельзя. Поэтому модуль:

- один раз загружает обои через `WallpaperManager`, уменьшает их и размывает (`Backdrop`, `BoxBlur`);
- рисует их внутри стекла с матрицей, которая прибивает картинку к дисплею и учитывает прокрутку обоев (хук `WallpaperManager#setWallpaperOffsets`);
- перед каждым кадром проверяет, не сдвинулась ли стеклянная view на экране (`GlassTracker`), и если сдвинулась, перерисовывает её. Иначе при листании страниц фон «ехал» бы вместе с иконками.

С живыми обоями стекло рисуется нейтральной матовой заливкой.

## Хуки

Хук всего один: `View#onAttachedToWindow` в процессе лаунчера. Нужные view он узнаёт по имени класса (`HotseatCellLayout`, `IconViewImpl`, `FolderIconViewImpl`, `AppWidgetHostView`, `*PageIndicator*` из `com.honeyspace.*`) и украшает их публичными API: фон (`GlassDrawable`), оверлей (`IconRimDrawable`) или обрезка по контуру. Внутренние методы One UI, которые меняются от сборки к сборке, модуль не трогает.

Подход (имена классов honeyspace, обои как подложка, AGSL) подсмотрен у BlurIcons. Код написан с нуля, из BlurIcons ничего не скопировано.

## Установка

1. Скачайте APK из артефактов GitHub Actions (вкладка **Actions**, сборка **Build APK**) или соберите сами: `./gradlew assembleRelease`.
2. Установите APK и включите модуль в LSPosed. В области действия (scope) должен быть **One UI Home**.
3. Перезапустите One UI Home. В приложении OneGlass для этого есть кнопка; без root остановите лаунчер вручную: Настройки → Приложения → One UI Home → Остановить.
4. Слайдеры и переключатели в приложении применяются к лаунчеру сразу, перезапуск для них не нужен. Наверху приложения есть превью, нарисованное тем же кодом стекла.

У виджетов Samsung свой фон. Чтобы было видно стекло, выставьте в настройках виджета прозрачность фона 100%.

## Если что-то не встало

Включите **Отладка → Диагностика** и перезапустите лаунчер. Модуль запишет в журнал LSPosed дерево view рабочего стола и строки `OneGlass: glass target …`, `icon geometry …`, `backdrop ready …`. По ним видно, какие классы нашлись в вашей сборке One UI.

## Требования

- One UI 8.5 (Android 16). Минимум Android 13 (API 33): AGSL `RuntimeShader` появился в нём.
- LSPosed (API 93+).
