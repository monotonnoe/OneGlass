# OneGlass

LSPosed-модуль для **One UI 8.5** (One UI Home + System UI): Liquid Glass в стиле **iOS 27**.

## Что внутри

**Движок стекла** — исходный код BlurIcons 7.1, предоставлен его владельцем. Перенесён в `com.monotonnoe.oneglass.engine`, получил свои адрес провайдера, broadcast-действия и имена файлов, поэтому ставится рядом с BlurIcons и не конфликтует с ним. Что он делает:

- **Рабочий стол:** стекло под иконками, папками, виджетами и строкой поиска; стеклянные иконки; углы виджетов как в iOS; скрытие бейджей; отключение затемнения иконок; стекло следует за зумом и прокруткой обоев; свет следует за наклоном телефона.
- **Экран блокировки:** стеклянные цифры часов, карточки уведомлений, нижние кнопки, полоска навигации, значок отпечатка.
- **Приложение настроек:** главный экран OneGlass.

**Дополнения OneGlass:**

- **Стеклянный док** по Figma «iOS 27 Widgets» → Playground: 357×99 pt, радиус 35, иконки 60 pt по центру. Рисуется тем же стеклом, что и иконки. Линза подобрана по рендеру Figma: высота 36.4 pt, сила 6.84 pt.
- **Сетка iOS 27** (по желанию, по умолчанию выключена): иконки 60 pt с шагом 90×97.8 pt, виджеты 158/338 × 158/354/550 pt.

Меню приложений One UI всегда остаётся стоковым.

## Установка

1. Установите APK (в `dist/` или в артефакте GitHub Actions).
2. В LSPosed включите модуль. Область действия: **One UI Home**, **System UI**, **Biometrics** (`com.samsung.android.biometrics.app.setting`).
3. Отключите BlurIcons: OneGlass уже содержит его движок, два модуля рисовали бы стекло дважды. Если включаете «Сетку iOS 27», отключите и SquareWidgets.
4. С живыми обоями выберите в настройках OneGlass картинку обоев (Рабочий стол → Картинка).
5. Перезапустите One UI Home и System UI. Проще всего перезагрузить телефон.

## Сборка

```sh
./gradlew assembleRelease
```

GitHub Actions собирает APK на каждый пуш.
